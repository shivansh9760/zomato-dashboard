🍽️ Zomato Restaurants Analysis Dashboard
📌 Project Overview

This Power BI project analyzes 100,000+ Zomato restaurant orders to provide business insights into revenue, customer behavior, delivery performance, restaurant performance, and overall operational efficiency.

The dashboard consists of 5 interactive report pages with KPIs, charts, slicers, and advanced Power BI visuals that help stakeholders monitor business performance and make data-driven decisions.
